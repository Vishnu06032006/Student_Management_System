System Architecture
Student & Staff Management System
Role-based institutional ERP — React 19 SPA · Node.js/Express REST API · MongoDB — 3-tier monolith
👤 Admin / Staff / Student (Browser)
Presentation Tier Client — React 19 + Vite Single-Page App runs entirely in the browser · no server-side rendering
React Router v7
RoleSelect → /login/:role → role-nested routes
ProtectedRoute
role gate + forces first-login password reset
AuthContext / ThemeContext
access token in memory only · theme in localStorage
Role Layouts
Admin / Staff / Student — grouped sidebar + topbar
Feature Pages
Students · Staff · Academics · Attendance · Timetable · Exams · Leave · OD · Announcements · Reports
Shared UI Library
DataTable · Modal · hand-built SVG DonutChart / BarChart
Axios API Client
attaches Bearer token · on 401 → silent refresh → retry
HTTPS REST + JSON  ⇄  Authorization: Bearer <accessToken> + httpOnly refreshToken cookie
Gateway Tier Express Middleware Pipeline — applied to every request server/app.js + middleware/*
Helmet
secure HTTP headers
CORS
origin locked to CLIENT_URL, credentials:true
express-rate-limit
tiered: global + login + OTP limiters
cookie-parser + json body
parses refresh cookie & request payloads
authenticate
verify JWT signature + re-check LIVE user status in DB on every request
restrictTo(role)
ADMIN / STAFF / STUDENT authorization
requirePasswordChanged
blocks all routes until first-login reset done
validate(zod schema)
request body validation, shared shape with frontend
Application Tier Express Application — Routes → Controllers → Services all business logic lives in the service layer

→
Controllers

→
Services
